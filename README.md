# TripWise — жеке саяхат жоспарлаушы

## Жоба сипаттамасы

TripWise — PHP, MySQL, HTML, CSS және JavaScript технологиялары арқылы әзірленетін жеке саяхат жоспарлауға арналған веб-қосымша.

Қосымша пайдаланушыларға саяхат жоспарларын құруға, баратын орындарын сақтауға, сапар күндерін белгілеуге және бюджетін басқаруға мүмкіндік береді.

## Жобаның мақсаты

- Жеке саяхат жоспарларын құру және басқару.
- Баратын қалалар мен орындарды сақтау.
- Саяхат күндері мен бюджетін белгілеу.
- Саяхат жоспарларын іздеу және сүзу.
- Пайдаланушыларды тіркеу және жүйеге кіру мүмкіндігін жасау.

## Негізгі функциялары

- Пайдаланушыны тіркеу және жүйеге кіру.
- Саяхат жоспарларын құру, көру, өңдеу және жою.
- Баратын орындар мен сапар күндерін басқару.
- Саяхат бюджетін бақылау.
- Іздеу және сүзу.
- Деректерді тексеру және қауіпсіздікті қамтамасыз ету.

## Негізгі беттер

1. `index.php` — басты бет.
2. `register.php` — тіркелу беті.
3. `login.php` — жүйеге кіру беті.
4. `dashboard.php` — жеке кабинет.
5. `trip_details.php` — саяхат туралы толық ақпарат.
6. `create_trip.php` — саяхат жоспарын құру.
7. `edit_trip.php` — саяхат жоспарын өңдеу.

## Дерекқор құрылымы

Жоба MySQL дерекқорындағы үш негізгі кестеден тұрады:

- `users` — пайдаланушылар туралы мәліметтер.
- `trips` — саяхат жоспарлары, бағыттары, күндері және бюджеті.
- `trip_places` — саяхат кезінде баруды жоспарлаған орындар.
