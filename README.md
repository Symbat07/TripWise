# TripWise — Жеке саяхат жоспарлаушы

## Жоба туралы

**TripWise** — пайдаланушыларға өз саяхаттарын жоспарлауға, баратын бағыттарын таңдауға және саяхат туралы ақпаратты бір жерде ұйымдастыруға арналған веб-қосымша.

Жобаның негізгі мақсаты — саяхат жоспарлау процесін жеңілдету және пайдаланушыларға ыңғайлы интерфейс ұсыну.

## Қолданылатын технологиялар

- **HTML5** — веб-беттің құрылымы.
- **CSS3** — сайттың дизайны және адаптивті интерфейсі.
- **JavaScript** — интерактивті элементтер.
- **PHP** — серверлік өңдеу және беттерді ұйымдастыру.
- **MySQL** — дерекқор (келесі кезеңдерде қосылады).

## Жобаның мүмкіндіктері

- Басты бет және жоба туралы ақпарат.
- Пайдаланушыны тіркеу формасы.
- Жүйеге кіру формасы.
- Жеке саяхаттар бетін көрсету.
- Саяхаттарды іздеу.
- Формалардағы деректерді тексеру.

## Орындалған жұмыстар

### 8-апта — Жоспарлау және репозиторий құру
- Жоба тақырыбы таңдалды.
- Жобаның мақсаты мен негізгі мүмкіндіктері анықталды.
- Негізгі беттер тізімі жасалды.
- Дерекқордың ER-диаграммасы дайындалды.
- GitHub репозиторийі құрылды.
- README файлы жасалды.

### 9-апта — Пайдаланушы интерфейсі (Frontend)
- Басты бет әзірленді.
- Тіркелу және жүйеге кіру беттері жасалды.
- Жеке саяхаттар беті жасалды.
- HTML, CSS және JavaScript қолданылды.
- Сайт дизайны адаптивті етіп ұйымдастырылды.

### 10-апта — PHP негіздері және серверлік құрылым
- HTML беттері PHP файлдарына бейімделді.
- Қайталанатын бөліктер `includes` папкасына шығарылды.
- `header.php` және `footer.php` файлдары жасалды.
- PHP беттеріне `include` қосылды.
- Формаларды өңдеу үшін `POST` әдісі қолданылды.
- Саяхаттарды іздеу үшін `GET` әдісі қосылды.
- Сервер жағында деректерді тексеру енгізілді.
- Жоба файлдарының құрылымы реттелді.

## Жобаны іске қосу

1. XAMPP бағдарламасын орнату.
2. Apache серверін іске қосу.
3. `TripWise` жобасын `C:\xampp\htdocs\` папкасына орналастыру.
4. Браузерден келесі мекенжайды ашу:

```text
http://localhost/TripWise/
```

## Келесі кезеңдер

- MySQL дерекқорын құру және PHP арқылы қосу.
- Пайдаланушыны тіркеу және авторизация жүйесін іске асыру.
- Саяхаттарды қосу, өңдеу және жою (CRUD).
- Іздеу, сүзу және сұрыптау мүмкіндіктерін кеңейту.
- Қауіпсіздік шараларын күшейту.
